# 排程表格式规格（ground truth）

`scripts/build_schedule.py` 已把下列排版全部写死，正常情况下**不需要手改样式**，本文件供核对与排障。

## 列定义（表头第 1 行，A–L）

| 列 | 表头 | 含义 | 填充 |
|----|------|------|------|
| A | 服务功能模块 | 平台，如 小程序 / PC | 按平台纵向合并 |
| B | 二级模块 | 一级功能域，如 公共 / 管理看板 / 日志 | 按模块纵向合并 |
| C | 功能点 | 具体功能点，如 时间筛选组件 / 目标状态分布 | 按功能点纵向合并 |
| D | 任务名称 | 一行一条开发任务，如 布局开发 / 查询条件 / 联调 | 每行一条 |
| E | 界面调用接口列表 | 调用接口清单 | 一般留空 |
| F | 类别 | 前端排程：前端开发 / 联调；后端排程：后端开发 | 必填 |
| G | 任务状态 | 默认「未开始」 | 脚本自动填；可用任务的 `status` 字段覆盖 |
| H | 预计工时（H） | 单条整数 1–7H（1 / 2 / 3 … 7）；>7H 拆多条 | 必填 |
| I | 开始日期 | 留空 | — |
| J | 结束日期 | 留空 | — |
| K | 预安排负责人 | 留空 | 留空；如需预填负责人，用任务的 `owner` 字段 |
| L | 备注 | 留空（复用/新建/联调判断只在对话总结里说明，不写进表） | 留空 |

## 合并规则

- A：同一平台的所有行纵向合并为一格。
- B：同一二级模块的所有行纵向合并。
- C：同一功能点的所有任务行纵向合并。
- 只有跨行数 > 1 才合并（单行不合并）。合并锚点单元格保持垂直居中。

## 样式常量

- **表头**：字体 `等线` 13pt 加粗，白字 `FFFFFFFF`，填充 `FF0070C0`（蓝），水平+垂直居中，四边 thin 边框。
- **正文**：字体 `Microsoft YaHei` 11pt，垂直居中，四边 thin 边框。
- **水平对齐**：A/B/F/G/H 居中；C/D 及其余列左对齐。
- **列宽**：A16.66 B25.66 D60.66 E23.66 F15.66 G14.66 H11.66 I18.66 K19.66 L53.66；C 用默认宽。
- **冻结**：`A2`（冻结表头行）。

> 任务拆解规则（新建/复用/联调判断、层级映射）见 `SKILL.md` 第 3 步，本文件只管格式。
