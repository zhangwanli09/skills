# skills

Reusable [Agent Skills](https://agentskills.io/home), triggered automatically by your prompts.

## Install

```bash
npx skills add zhangwanli09/skills
```

## Skills

- [dev-schedule](./skills/dev-schedule/SKILL.md) — Turn a PRD into a formatted dev scheduling xlsx with honest hour estimates.
- [monthly-work-summary](./skills/monthly-work-summary/SKILL.md) — Build a monthly work report from your git commits. Manual invocation only (`/monthly-work-summary`).
- [zentao](./skills/zentao/SKILL.md) — Turn ZenTao bugs, stories, and tasks into dev-ready tickets via the `zentao` CLI, and write clarifications and fix notes back. Requires ZenTao open-source 16.x and [`zentao16-cli`](https://www.npmjs.com/package/zentao16-cli) (`npm install -g zentao16-cli`, Node.js 22.12+).
